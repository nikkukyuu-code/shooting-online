# 横スクロール シューティング オンライン対戦

ブラウザで遊べる横スクロール・シューティングのオンライン対戦ゲームです。

**バージョン:** メニュー下部に `vX.Y.Z` とアクセス数を表示

**Play:** https://nikkukyuu-code.github.io/shooting-online/

## 遊び方

1. スマホを縦向きにしてページを開く
2. **対戦相手を探す** … 自動マッチ（見つからなければ CPU 対戦）
3. **部屋を作る** … 部屋名（または自動番号）でホストになる
4. 部屋名を入力して **スタート** … その部屋に入室

### 操作

- **中央ペイン（自機フィールド）** をドラッグ … 自機を上下・前後に移動（自動ショット）
- **下ペイン（操作パネル）** をタップ … 取得済みアイテムを発動
- 上ペイン（相手ビュー） … 移動・アイテム操作なし
- **ストップ** … メニューに戻る
- キーボード … ↑↓←→ / W A S D で移動（←A=後退、→D=前進）、Space / Enter でアイテム発動

### アイテム

敵を倒すとアイテムが出ます（画面下の案内: **敵を倒してアイテムを取得してください**）。

| 名前 | 効果 |
|------|------|
| 追尾ミサイル | 一定時間ホーミング弾 |
| レーザー | 一定時間直線レーザー |
| 対戦相手へ敵キャラを送信 | 相手フィールドに敵を送る |
| 対戦相手を直接攻撃 | 相手の HP を直接削る |

勝敗表示: **あなたの勝ちです** / **あなたの負けです**

待機中表示: **対戦相手を待っています**

## 画面レイアウト（縦持ち・3段）

- **上** 約 30% … 対戦相手のライブビュー（暗め表示）
- **中** 約 45% … 自分のプレイフィールド（ここで自機を操作）
- **下** 約 25% … 操作パネル（紫〜青灰色。ステータス文言・アイテム待ち列。タップで発動）

## 技術

- HTML5 Canvas + ES Modules
- 通信: [PeerJS](https://peerjs.com/)（ブラウザ間 P2P）
- 効果音: Web Audio API
- 静的ホスト（GitHub Pages）で動作

## ローカル確認

```bash
cd shooting-online
python3 -m http.server 8080
# http://localhost:8080 を開く
```

※ `file://` では ES modules / PeerJS が制限されることがあるため、ローカルサーバー推奨です。
