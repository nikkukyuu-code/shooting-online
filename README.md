# 横スクロール シューティング オンライン対戦

ブラウザで遊べる横スクロール・シューティングのオンライン対戦ゲームです。

## 遊び方

1. スマホを縦向きにしてページを開く
2. **対戦相手を探す** … 自動マッチ（見つからなければ CPU 対戦）
3. **部屋を作る** … 部屋名（または自動番号）でホストになる
4. 部屋名を入力して **スタート** … その部屋に入室

### 操作

- 画面上側（自機フィールド）をドラッグ … 自機の上下移動（自動ショット）
- 下側（対戦相手ビュー）をタップ … 取得済みアイテムを発動
- **ストップ** … メニューに戻る
- キーボード … ↑↓ / W S で移動、Space / Enter でアイテム発動

### アイテム

敵を倒すとアイテムが出ます（画面下の案内: **敵を倒してアイテムを取得してください**）。

| 名前 | 効果 |
|------|------|
| 追尾ミサイル | 一定時間ホーミング弾 |
| レーザー | 一定時間直線レーザー |
| 対戦相手へ敵キャラを送信 | 相手フィールドに敵を送る |
| 対戦相手を直接攻撃 | 相手の HP を直接削る |

勝敗表示: **あなたの勝ちです** / **あなたの負けです**

## 画面レイアウト

- 上部 約 65% … 自分のフィールド
- 下部 約 35% … 暗くした対戦相手のライブビュー

## 技術

- HTML5 Canvas + ES Modules
- 通信: [PeerJS](https://peerjs.com/)（ブラウザ間 P2P）
- 静的ホスト（GitHub Pages など）で動作

## ローカル確認

```bash
cd shooting-online
python3 -m http.server 8080
# http://localhost:8080 を開く
```

※ `file://` では ES modules / PeerJS が制限されることがあるため、ローカルサーバー推奨です。
